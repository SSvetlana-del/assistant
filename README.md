# IT Навигатор — AI-консультант образовательной платформы

Учебный проект для портфолио продакт-менеджера. Gradio + LangGraph + LangChain/GigaChat + Pydantic + PostgreSQL (Supabase). SQLite доступна для локальной разработки.

## Быстрый запуск

Нужен Python 3.12. Команды выполняются в папке проекта.

```bash
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.lock
cp .env.example .env
# Windows: Copy-Item .env.example .env
# Впишите GIGACHAT_CREDENTIALS в .env, затем:
python app.py
```

Откройте http://127.0.0.1:7860. Для установки только прямых зависимостей вместо зафиксированного окружения: `pip install -r requirements.txt`.

`GIGACHAT_CREDENTIALS` — ключ авторизации проекта GigaChat API (Authorization Key), не пароль Сбер ID и не временный access_token. Получить его можно в кабинете разработчика: https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart . Для личного проекта используется `GIGACHAT_API_PERS`. Ключ хранится только в `.env`, не в браузере, не в git и не в переписке. Модель можно изменить переменной `GIGACHAT_MODEL`.

TLS-проверка включена. Если нужен доверенный сертификат API, установите официальный сертификат в систему или задайте `GIGACHAT_CA_BUNDLE`. Не отключайте проверку TLS.

Без ключа приложение запускается: доступны каталог, запись и подтверждение, а чат сообщает о недоступности модели. Это не имитация ответа GigaChat. Реальные ответы и классификацию нужно проверить после подключения своего ключа.

## Что умеет

- Цена: отдельная ветка читает суммы из каталога, без генерации чисел моделью.
- Выбор: уточняет цель, опыт и время; рекомендует до двух курсов, объясняет компромиссы.
- Общее: отвечает по FAQ и карточкам, признаёт отсутствие данных.
- Запись: чат направляет в форму. После проверки параметров и явного подтверждения создаётся реальная запись в выбранной базе (Supabase или локальная SQLite), появляется сообщение в чате и TXT-файл с номером, курсом, именем, нагрузкой и условиями.
- История: сохраняется в выбранной базе; идентификатор текущего диалога хранится в BrowserState. После обновления страницы и перезапуска приложения можно продолжить диалог в том же браузере. В GigaChat отправляются последние 30 сообщений; вся история хранится в БД.
- Другой браузер получает отдельный диалог. «Новый диалог» выдаёт новый идентификатор и не удаляет старую историю/записи.

**Запись настоящая только внутри учебного приложения.** Интеграции с Stepik или Практикумом нет; оплата, доступ к материалам и зачисление у автора не выполняются. Email и Telegram не подключены — выбран канал «чат + файл».

## Каталог и факты

`data/courses.json`: 17 карточек. Направления: QA, аналитика данных, системная, продуктовая и бизнес-аналитика, управление проектами и продуктом, дизайн. Есть начальные программы и программы для людей с опытом. Разработки как отдельного направления нет; SQL входит в аналитику.

В каждой карточке есть ID, название, направление, уровень, стоимость в рублях (`null`, если не подтверждена), длительность, формат, требования, темы и URL источника. Дата проверки: 18.11.2026. Названия, уровни и длительность взяты из открытых карточек/каталогов; темы — короткие описательные теги, а не полная программа обучения. Точные входные требования перенесены только там, где они подтверждены. Если факт не проверен, это явно указано.

Источники:

Цены большинства программ Практикума намеренно `null`: актуальный тариф не подтверждён, бесплатный вводный модуль не выдаётся за бесплатную полную программу. Приложение не скрейпит источники на лету. Чтобы расширить каталог, обновите JSON и перезапустите приложение.

## Паттерны и место в коде

| Паттерн | Где и зачем |
|---|---|
| Router / conditional workflow | `advisor/engine.py`: LangGraph классифицирует запрос и выбирает ветку price/selection/general/enroll/error. |
| Strategy | Отдельные обработчики цены, выбора, общих вопросов и записи имеют разные правила поведения. |
| Structured output | Схема Pydantic `Route` задаёт допустимые интенты и список ID; неизвестные ID фильтруются. |
| Grounded generation / context injection | Для небольшого каталога весь JSON подставляется в системный контекст. Это не векторный RAG: для 17 карточек отдельная векторная БД не нужна. |
| Repository | `advisor/storage.py`: SQL и транзакции изолированы от Gradio и модели. |
| Explicit confirmation / human in the loop | `app.py`: предварительный просмотр → отдельное подтверждение; LLM не имеет доступа к записи. |
| Idempotent command | Уникальность `(session_id, course_id)`, транзакция `BEGIN IMMEDIATE` и одноразовый токен защищают от дублей. |
| Conversation memory | PostgreSQL/SQLite + BrowserState; модель получает последние 30 сообщений, история не смешивается между сессиями. |

Граф управляет консультацией, а детерминированная форма — записью. Свободно действующий агент здесь не нужен: это уменьшает непредсказуемость и облегчает тестирование.

## Проверки

```bash
pip install pytest
python -m pytest -q
```

Тесты покрывают четыре ветки, память и изоляцию, достоверность цены, сбои провайдера, неизвестные ID, сохранение записи, одноразовое подтверждение, срок действия черновика и защиту от дублей. В unit-тестах вместо GigaChat используется явно обозначенная тестовая заглушка. Они не доказывают качество рекомендаций реальной модели.

## Ограничения прототипа

- Нет авторизации и восстановления диалога на другом устройстве. Идентификатор браузера действует как ключ доступа к диалогу; это локальный прототип.
- Единственная очередь обеспечивает один одновременный обработчик, подходящий для персонального GigaChat API. Для нагрузки нужны очередь, rate limits и аккаунты.
- На Render используется Supabase и постоянная переменная `BROWSER_SECRET`; локальные SQLite и `browser.secret` хранятся на диске. Не включайте их в Git; используйте вымышленные имена в демо.
- При публичном размещении добавьте аутентификацию, квоты и политику хранения данных. Учитывайте условия личного Freemium GigaChat. По умолчанию `share=False`, сервер доступен только локально.
- Старые диалоги и временные подтверждения автоматически не удаляются. Для долгого хостинга нужен срок хранения. «Новый диалог» не является удалением данных.

## Для продуктового кейса

Сформулируйте гипотезу: диалоговый подбор помогает выбрать релевантный курс быстрее каталога. Сравните два сценария на пользовательских тестах; фиксируйте время выбора, соответствие рекомендаций цели и долю завершённых записей. Отдельно оцените ответы на вопросы о цене, неизвестных условиях, смене цели в диалоге и неподходящих программах. Не подменяйте результаты тестов предполагаемым ростом покупок.

Проверено при сборке: 15 автоматических тестов прошли; браузерная проверка подтвердила сохранение записи, скачивание TXT, восстановление истории после обновления и изоляцию нового браузера. Реальный запрос к GigaChat не выполнялся — ключ не предоставлен. Совместимость схемы с реальным адаптером проверена без сетевого запроса.

## Render

Готова конфигурация бесплатного Web Service: `render.yaml`. Пошаговая инструкция, секреты и ограничения хранения описаны в `RENDER.md`. При наличии `PORT` используется порт Render. В актуальной конфигурации `DATABASE_URL` указывает на Supabase, а история и записи переживают перезапуск Render. Начните с `SUPABASE.md`.
